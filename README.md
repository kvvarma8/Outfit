# His & Hers Closet

A single-page wardrobe planner. Open `index.html` in a browser (or serve it with GitHub Pages).

- **Closet** – upload photos of clothes for him, her or both. Color is guessed from the photo and type from the file name; edit either on each card. Opened as a claude.ai artifact, the closet and shopping list are shared online with everyone you give access; opened as a plain file they stay in your browser (IndexedDB).
- **Outfits** – enter a city to pull a 7-day forecast (Open-Meteo, no key needed) or set the temperature and sky by hand, pick where you're going, and get three looks each for him and her. Missing pieces for that plan (e.g. a rain jacket) are flagged.
- **Staples** – a classic capsule checklist for each of you, matched against your closet.
- **Shopping list** – add missing staples or gaps with one click, tick off what you buy, copy the list.
